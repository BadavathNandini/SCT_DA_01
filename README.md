# Excel Sales Dashboard

## Project Overview

This project is an interactive Excel Sales Dashboard created using the Sample Superstore dataset.

## Features

* Total Sales KPI
* Total Profit KPI
* Profit by Category Analysis
* Sales Trend Over Time
* Sales by Region
* Sales by Segment
* Interactive Slicers

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Visualization

## Dashboard Preview

The dashboard provides insights into sales performance, profitability, regional performance, and customer segments.

## Skills Demonstrated

* Data Cleaning
* Data Analysis
* Dashboard Design
* Excel Reporting
* Business Intelligence
